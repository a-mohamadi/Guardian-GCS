**A modern Windows Ground Control Station for monitoring, controlling, and managing robotic systems.**

Guardian GCS is a modern, operator-focused Ground Control Station built for real-time robot monitoring and control.  
It provides a clean single-window dashboard with live telemetry, map, video, teleoperation, and full bilingual support (English + Persian).

## Features

- **Live Dashboard** — Battery, speed, signal, mode, depth, voltage, current, motor & GPS status
- **Interactive Map** — Real-time robot position, home point, route planning, fullscreen mode
- **Live Camera** — Video feed with snapshot & recording, fullscreen support
- **Telemetry** — Recording, replay, and expandable charts
- **Event Log** — Searchable, severity filtering, export, notification priorities
- **Teleoperation** — Keyboard + Gamepad support with safety features (Hold-to-Drive, Drive-Arm, deadzone)
- **Security** — App lock, password management, user sessions
- **Localization** — Full English + Persian (Farsi) with right-to-left layout
- **Themes** — Dark, Light, Glass, and High Contrast
- **Demo Mode** — Fully functional simulator so you can explore everything without a real robot
