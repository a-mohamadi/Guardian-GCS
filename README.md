# Guardian GCS

**A modern Windows Ground Control Station for real-time monitoring, control, and management of robotic systems.**

[![Latest Release](https://img.shields.io/github/v/release/a-mohamadi/Guardian-GCS?include_prereleases)](https://github.com/a-mohamadi/Guardian-GCS/releases)

[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Languages](https://img.shields.io/badge/UI-English%20%7C%20Persian-blue)](https://github.com/a-mohamadi/Guardian-GCS)

Guardian GCS is a single-window desktop application designed for operators who need a clear, reliable interface to monitor and control remote robots. It combines live telemetry, mapping, video, teleoperation, and system management in one coherent workspace, with full support for both English and Persian (including right-to-left layout).

## Features

- **Live Dashboard** — Battery, speed, signal strength, mode, depth, voltage, current, motor and GPS status
- **Interactive Map** — Real-time robot position, home point, route planning, and fullscreen view
- **Live Camera** — Video feed with snapshot, recording, and fullscreen support
- **Telemetry** — Recording, playback, and expandable charts
- **Event Log** — Searchable log with severity filtering, export, and notification priorities
- **Teleoperation** — Keyboard and gamepad input with safety features (Hold-to-Drive, Drive-Arm, deadzone)
- **Security** — Application lock, password management, and user sessions
- **Localization** — Full English and Persian support with automatic RTL layout
- **Themes** — Dark, Light, Glass, and High Contrast
- **Demo Mode** — Fully functional simulator so you can explore the interface without hardware

## Current Status

This is an early public beta.  

Demo Mode is fully operational and uses simulated data. Real robot transport (TCP/UDP/serial) and parts of the server connectivity layer are still under active development and may not yet be stable.

Feedback is highly valued and directly shapes the next releases.
