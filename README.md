## Overview

Guardian GCS is a modern ground control station designed for real-time monitoring, control, and management of robotic systems.  
It provides a clean and user-friendly interface with support for both **Persian** and **English**, multiple themes, and a fully functional **Demo Mode**.

---

## Features

- Robot control and real-time monitoring
- Live telemetry and robot status
- Live map with robot positioning
- Route planning and autonomous movement
- Live video monitoring
- Local and server connectivity
- User authentication and access control
- System logs and operational monitoring
- Persian and English language support
- Multiple themes and appearance settings
- **Demo mode** with simulated data (no real robot required)

## Beta Status

This is an **early public beta**.  
Some features (especially server connectivity and parts of the infrastructure) are still under active development and may not be fully stable yet.

The **Demo Mode** is fully functional and uses simulated data so you can explore the application without connecting a real robot.
